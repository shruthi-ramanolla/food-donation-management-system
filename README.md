## 📌 Overview

The **Food Donation Management System** is a responsive web application that connects food donors directly with NGOs and beneficiaries — creating a streamlined, efficient pipeline to reduce food wastage and fight hunger.

> 💡 *"One-third of all food produced globally is wasted. This project is our step toward changing that."*

---

## 🎯 Problem Statement

Every day, tonnes of surplus food go to waste while millions go hungry. The gap between donors and those in need exists due to a lack of coordination and an accessible platform. This system solves that by digitizing the entire donation workflow.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 🙋 Donor Registration | Donors can register, log in, and submit food donation details |
| 🏢 NGO Dashboard | NGOs can view, accept, and manage incoming donation requests |
| 🛡️ Admin Panel | Admins verify requests, assign NGOs, and oversee the full pipeline |
| 📦 Donation Tracking | Real-time status updates from submission to delivery |
| 📱 Responsive Design | Works seamlessly across desktop and mobile devices |
| 🔐 Login System | Secure role-based access for Donor, NGO, and Admin |

## 👥 User Roles & Modules

```
┌─────────────┐     ┌───────────────┐     ┌──────────────┐     ┌──────────────────┐
│    DONOR    │────▶│     ADMIN     │────▶│     NGO      │────▶│   BENEFICIARY    │
│             │     │               │     │              │     │                  │
│ Submit food │     │ Verify & assign│     │ Accept pickup│     │ Receive donation │
│ donation    │     │ to NGO        │     │ Update status│     │                  │
└─────────────┘     └───────────────┘     └──────────────┘     └──────────────────┘
```

### 🙋 Donor Module (`donor.html`)
- Register and log in securely
- Add food donation details (type, quantity, expiry)
- Track real-time donation status

### 🛡️ Admin Module (`admin.html`)
- Verify incoming donation requests
- Assign NGOs based on location
- Manage users and system data

### 🏢 NGO Module (`ngo.html`)
- View assigned donations
- Accept pickup requests
- Update delivery and distribution status

### 🤝 Beneficiary Module
- Receive food through NGO coordination

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge)
- [VS Code](https://code.visualstudio.com/) with Live Server extension *(recommended)*

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/shruthi-ramanolla/food-donation-management-system.git

# 2. Navigate into the project
cd food-donation-management-system

# 3. Open in browser
# Option A: Just open index.html directly in your browser
# Option B: Use Live Server in VS Code for hot reload
```
